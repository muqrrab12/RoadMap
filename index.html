1. The rules that make this plan work

1 hour lecture / day

Never more. Lectures are capped; the rest of the day is practice, not more videos.

45 min practice

Every lecture day ends with code written by you — no exceptions, no "I'll practice later".

Split long sessions

DSMP sessions are long. Split one session across 2–3 days instead of bingeing it.

One path per topic

Never watch two playlists for the same topic. Pick one, finish it, move on.

GitHub proof weekly

Something pushed every week. An empty GitHub means the plan has stalled, whatever the watch history says.

Triage, don't complete

Full DSMP is ~389 hours — at 1 hour/day that is ~1.5 years. This plan selects modules. Everything is not watched.

2. The spine — in this exact order

  1. DSMP (selected modules) — Pandas finish, Data Viz, EDA, SQL, Statistics
  2. 100 Days of Machine Learning — primary source for ML algorithms
  3. 100 Days of Deep Learning — concepts (~52 hours total) + PyTorch for implementation
  4. CampusX NLP — theory foundations, then practical text projects
  5. Generative AI with LangChain — LLMs, RAG, vector databases
  6. Agentic AI with LangGraph — tool-using agents, memory, state
  7. Deployment — FastAPI, Docker, MLflow
  8. Portfolio & jobs — deployed projects, resume, LinkedIn, interviews

Do not learn Computer Vision deeply as a separate track. The CNN part of Deep Learning covers enough for an AI/ML engineer in 2026; NLP + GenAI is the track that pays off here.

4. Month by month — November 2026 to August 2027

Each month has 4 weeks. Weekly rhythm everywhere: Mon–Fri 1 hour lecture + 45 min practice, Saturday mini-project, Sunday revision + GitHub push.

Source: DSMP Pandas modules (remaining part only).

  • Week 1: Series, DataFrames, indexing, selection
  • Week 2: groupby, merge, join, pivot tables
  • Week 3: missing data, apply, string/date handling
  • Week 4: full Pandas project — clean and analyze one real messy dataset end to end

Pass condition: you can do groupby, merge and pivot without looking up the basics.

Source: DSMP Data Viz + EDA modules. Booster: Krish Naik EDA one-shot if stuck.

  • Week 1: Matplotlib foundations, plots that answer questions
  • Week 2: Seaborn, distributions, relationships, categorical plots
  • Week 3: EDA workflow on a Kaggle dataset — questions first, plots second
  • Week 4: complete EDA report as a notebook on GitHub

Pass condition: a full EDA notebook that reads like an analysis, not a plot dump. DSMP Assessment 2 (NumPy + Pandas + Data Viz + EDA) completed.

Source: DSMP SQL modules.

  • Week 1: SELECT, WHERE, ORDER BY, LIMIT, filtering
  • Week 2: JOINs (inner, left, right, full) and set logic
  • Week 3: GROUP BY, aggregations, HAVING, subqueries
  • Week 4: 20+ queries on a real database + one small SQL project

Pass condition: you can write any join/aggregation query confidently. DSMP Assessment 3 (SQL) completed.

Source: DSMP Statistics modules. Booster: Krish Naik Complete Statistics (6 hours) for revision.

  • Week 1: distributions, mean/variance, sampling
  • Week 2: probability, Bayes, confidence intervals
  • Week 3: hypothesis testing, p-values, A/B testing logic
  • Week 4: statistics project — test a real hypothesis on real data, write it up

Pass condition: you can explain p-values, distributions and bias–variance in plain words. DSMP Assessment 4 (Statistics) completed.

Source: 100 Days of Machine Learning (primary). DSMP ML sessions only as revision.

  • Week 1: regression — simple, multiple, polynomial; metrics (MSE, MAE, RMSE, R²)
  • Week 2: gradient descent (batch, stochastic, mini-batch); regularization (Ridge, Lasso)
  • Week 3: classification — logistic regression, kNN, Naive Bayes; metrics (precision, recall, F1, ROC)
  • Week 4: project — house-price regression and a classifier, both with proper train/test evaluation

Pass condition: two evaluated models on GitHub with a written explanation of every metric you report.

Source: 100 Days of Machine Learning (continued).

  • Week 1: decision trees, Random Forest, bagging
  • Week 2: boosting — AdaBoost, Gradient Boosting, XGBoost
  • Week 3: SVM, PCA, clustering (K-Means, hierarchical, DBSCAN)
  • Week 4: end-to-end ML project with a clean pipeline (preprocessing + model + tuning + evaluation)

Pass condition: one pipeline-based project on GitHub. DSMP Assessment 5 (ML Linear Model) completed; one DSMP case study started.

Source: 100 Days of Deep Learning (Days 1–~54). Implement in PyTorch.

  • Week 1: perceptron, MLP, forward propagation
  • Week 2: backpropagation, loss functions, weight initialization
  • Week 3: optimizers (SGD + momentum, Adam), batch normalization, tuning
  • Week 4: CNN project — image classifier with transfer learning

Pass condition: a CNN classifier on GitHub, built in PyTorch, with training curves you can explain.

Source: 100 Days of Deep Learning (RNN/LSTM, transformers) + CampusX NLP playlist.

  • Week 1: RNN, LSTM, GRU — sequence thinking
  • Week 2: attention, transformers — self-attention, multi-head, positional encoding
  • Week 3: NLP theory — preprocessing, tokenization, BoW, TF-IDF, Word2Vec
  • Week 4: project — sentiment classifier with a full text pipeline

Pass condition: you can explain attention in plain words and ship a text classifier.

Source: CampusX Generative AI with LangChain, then Agentic AI with LangGraph.

  • Week 1: LLM basics, prompts, structured output, chains
  • Week 2: RAG — document loaders, splitters, vector stores, retrievers
  • Week 3: RAG chatbot project on your own documents
  • Week 4: LangGraph agents — tools, memory, state; one tool-using agent project

Pass condition: a RAG chatbot and an agent, both on GitHub, both actually working — not demos that only run once.

Source: CampusX FastAPI / Docker / MLflow courses + DSMP career sessions.

  • Week 1: FastAPI — wrap a model in an API; Docker — containerize it
  • Week 2: MLflow — track experiments; deploy one project end to end
  • Week 3: portfolio — GitHub cleaned up, README per project, LinkedIn rebuilt, resume written
  • Week 4: job sprint — 10+ real applications, interview prep (explain your 3 best projects out loud)

Pass condition: two deployed projects with live links, a finished portfolio, and applications actually sent.
